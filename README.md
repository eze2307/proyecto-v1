# Proyecto V1

Proyecto colaborativo full-stack con documentación integrada en Obsidian.

## 📁 Estructura del Proyecto

- `frontend/`: Aplicación React + TypeScript + HTML/CSS.
- `backend/`: Servicios y API (Node.js / Java).
- `database/`: Scripts SQL, migraciones y esquemas de base de datos.
- `docs-vault/`: Bóveda de Obsidian compartida para documentación, notas de reuniones y arquitectura.

## 🚀 Cómo empezar

### 1. Clonar el repositorio
```bash
git clone <URL_DEL_REPOSITORIO>
cd proyecto-v1
```

### 2. Abrir la Bóveda de Obsidian
1. Abre **Obsidian**.
2. Haz clic en **"Open folder as vault"** (Abrir carpeta como bóveda).
3. Selecciona la carpeta `docs-vault/`.

### 3. Reglas de trabajo en Git
- Nunca trabajar directamente sobre `main`.
- Crear una rama por cada tarea: `git checkout -b feature/nombre-tarea`.
- Al terminar, subir la rama y abrir una **Pull Request** para revisión.
